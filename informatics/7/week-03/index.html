Единицы измерения информации. Урок 2

Сегодня переводим числа напрямую между двоичной, восьмеричной и шестнадцатеричной системами — без промежуточного перехода в десятичную.

📝 Все вычисления и группировку разрядов выполняй в тетради. На сайт вводи только итоговый ответ.
2 ↔ 8: группируем двоичные цифры по 3 справа налево.
2 ↔ 16: группируем двоичные цифры по 4 справа налево.
Прогресс0 из 3 миссий

Миссия 1 · Проверь правило

Определи, верны ли утверждения о быстрых переводах между системами счисления.
1. Для перевода из двоичной системы в восьмеричную число делят на группы по 3 бита справа налево.
2. Для перевода из двоичной системы в шестнадцатеричную число делят на группы по 3 бита.
3. Если слева не хватает битов для полной группы, можно дописать ведущие нули.
4. В шестнадцатеричной системе символ F соответствует числу 15.
5. Восьмеричная цифра 7 переводится в двоичную как 1111.

Миссия 2 · Двоичная ↔ восьмеричная

Группируй биты по три. Решение запиши в тетрадь, на сайт введи только ответ.
1. Переведи в восьмеричную систему
1011012 =
8
2. Переведи в восьмеричную систему
1110102 =
8
3. Переведи в восьмеричную систему
10101112 =
8
4. Переведи в двоичную систему
738 =
2
5. Переведи в двоичную систему
1458 =
2

Миссия 3 · Двоичная ↔ шестнадцатеричная

Группируй биты по четыре. Для шестнадцатеричных цифр используй A, B, C, D, E, F.
1. Переведи в шестнадцатеричную систему
101011112 =
16
2. Переведи в шестнадцатеричную систему
111101002 =
16
3. Переведи в шестнадцатеричную систему
1001101012 =
16
4. Переведи в двоичную систему
3C16 =
2
5. Переведи в двоичную систему
A716 =
2

Урок 2 завершён!

Ты потренировался переводить числа напрямую между системами 2, 8 и 16.

Главное правило: 2 ↔ 8 — группы по 3 бита, 2 ↔ 16 — группы по 4 бита.
