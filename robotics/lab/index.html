Карта подключений для Arduino Uno: соединяй компоненты строго по обозначениям ниже. Расположение ножек на разных модулях может отличаться — смотри подписи на своей детали.

Соединения

Перед подключением USB покажи собранную схему учителю. Светодиод подключай через токоограничивающий резистор. Не подавай 5V на модули, рассчитанные на 3.3V.

🚀 Make!

  1. Выбери кейс и подготовь все указанные детали.
  2. Отключи питание Arduino и собери соединения по карте.
  3. Покажи схему учителю перед включением питания.
  4. Во вкладке «Понимаю код» скачай файл .ino, открой его в Arduino IDE.
  5. Подключи плату, выбери модель Arduino Uno и COM-порт, загрузи программу.
