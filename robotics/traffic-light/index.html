Три светодиода, три резистора и немного кода — собери светофор, который переключается сам!

Нажми на компонент, чтобы узнать, зачем он нужен. Сегодня мы построим настоящий трёхцветный светофор.

🧩 Тренажёр: как соединены отверстия макетной платы →

📚 Все устройства в справочнике →

👆 Выбери любую деталь выше.
💡 Важно: короткую ножку каждого светодиода подключаем к GND, а длинную — к цифровому пину через резистор.

🔧 Собираю электрическую схему

🧩 Не помнишь, какие отверстия соединены? Открой тренажёр →

Порядок сборки: 1) GND → синяя шина; 2) поставь три LED так, чтобы их ножки не находились в одной контактной группе; 3) каждому LED добавь резистор; 4) красный соедини с D8, жёлтый — с D10, зелёный — с D12; 5) проверь полярность и покажи схему учителю.

Подключай при отключённом USB-кабеле. На рисунке показана логика электрических соединений, а не точное размещение элементов на макетной плате.

Три отдельные цепи: D8 → резистор → красный LED → GND; D10 → резистор → жёлтый LED → GND; D12 → резистор → зелёный LED → GND.
Перед практикой открой интерактивную макетную плату и проверь себя: куда подключаем короткую ножку LED?

▶ Симуляция светофора
Это учебная визуальная модель: она показывает логику программы и переключение сигналов. Она не проверяет физическую электрическую схему.

Нажми «Запустить», чтобы посмотреть последовательность.
Для настоящей электронной симуляции позже можно встроить подготовленный проект Wokwi. Эта демонстрация пока воспроизводит последовательность из нашего кода.


🚀 Make! Запусти настоящий Arduino
Теперь перенеси программу на настоящий микроконтроллер.
  1. Собери цепь по схеме и покажи учителю.
  2. Скачай файл traffic_light.ino.
  3. Открой файл в Arduino IDE.
  4. Подключи плату через USB, выбери правильные плату и порт.
  5. Нажми Upload / Загрузить и проверь светофор!
🔥 Челлендж для быстрых: измени программу так, чтобы зелёный LED мигнул трижды перед включением жёлтого. Попроси учителя проверить результат.
